## ИГРА И WINDY

передвижение | Left, Right  
```
ускорение 0.046875, тормоз 0.5, ускорение (воздух) 0.09375, замедление 0.046875,
максимальная скорость разбега 6, максимальная скорость 16, толкание 1
```

смотреть вверх, вниз | Up, Down `стоя на земле`  
прыжок | jump  
```
сила 6.5, при отпускании прыжка если скорость Y > 4 и Y < 6.5 то Y = 4 иначе если Y > 6.5 то Y *= 0.75
```

атака | attack  
```
урон: 10, 7, 5 (от сложности)
```
парирование | parry  

восстановление 180 кадров, и хп идут сначала в дополнительное потом основное (только при парировании)  
* шипы: радиус срабатывания 160, если (относительно шипа) abs(Y) < 7 то Y = 8  
иначе Y = abs(Y) + 2.75, X не изменяется  
* враг: взовисимости от типа врагов, либо X = 6 * -sin(угол), Y = 6 * cos(угол), либо ничего  
* пуля: отправляет пулю обратно. Больше не наносит урон игроку.  
Взовисимости от типа пули, либо `непроропотоно`, либо ничего  
* возврат хп: вражеские атаки: до 8 кадров 1 хп;  
* остальное: до 8 кадров 1 хп, время восстановления снимается  

WindyDash | Down зажать и attack нажимать или зажать `земля`  
```
от 6 до 10, кадр нажатия 0.75, кадр зажатия 0.03125, иначе -(int)( (скорость - 6) / 0.125 ) / 256
```

атака вверх | Up зажать и attack нажать  
```
с земли как прыжок, но второго условия нету  
воздух скорость Y < 6.5 / 2 то Y = 6.5 иначе Y += 6.5 / 2
урон: 15, 12, 8 (от сложности)
```

атака вниз | Down зажата и attack начать `воздух`  
```
X += sign(X) * (sign(X) * abs(X)) switch 
    { < -1 => 4.5, 
      < 0 => -1.5 * abs(X) + 3, 
      < 6 => 3, 
      _ => -0.3 * abs(X) + 4.8 }
урон: (12, 10, 7) + abs(X) / (3, 4, 7) (от сложности)
```

шар | Down `в движении на земле`  
```
замедление 0,0234375, гравитация подъем и спуск: 0,07515 и 0,3125
урон: (1.5, 1, 0.5) каждый 6 кадр (от сложности)
```

## ФИЗИКА И НЕТОЛЬКО

падение
```
при abs(скорости) < 1.5 и abs(угол) > 25  
{  
    то управление блокируется на 15 кадров  
    падение при abs(угол) > 85  
}
```

за листя `+хп при 40, а +жизнь при 200`  

урон  
```
стандартный: скорость X = 4 * -sin(угол), Y = 4 * cos(угол)
шипы: радиус срабатывания 160 и относительно (шипа) Y < 0.5, то урон
враги: взовисимости от типа врагов, либо стандартный, либо X = 0, Y = 0
пули: взовисимости от типа пули, либо стандартный, либо X = 0, Y = 0
```  

в воду:  
```
X *0.5 Y *0.25
```

из воды:  
```
X *1 Y *1.5
```  
воде  
```
ускорение, тормоз, ускорение (воздух), WindyDesh (/ 2 (+ 1.25 если атакует (не зависит от воды)))  
максимальная скорость разбега, гравитации (земля)
    (для обычного и шар в подъем и спуск), замедление (обычный и шар),  
отпускании прыжка, толкание, атака вниз (/ 2)  
гравитация (воздух) (/ 3.5)  
пыжок, атака вверх (- 3)  
```

приземление `всё под abs(всё), в условиях`  
```
угол < 135 : скорость = X * cos(угол) + Y * sin(угол)
угол - напровление X и Y < 5 градусов : скорость = X * cos(угол) + Y * sin(угол)
иначе скорость = Y = 0
```

гравитация  
```
воздух: -0.21875  
земля: при 26 < угол < 155  
значение 0.125  
```

споротивление воздуха
```
при 4 > Y > -1  
X = X - (int)(X / 0.125) / 256
```

## ОБЕКТЫ

ветреной поток  
```
если (относительно ветреной поток) Y < сила ветреного потока то Y = сила ветреного потока иначе Y = Y + 1, X = X / 2 
```

```
чтобы попасть на спецстадию, надо 
найти ключ и успеть добежать до финиша
1, 2, 3, 4, 5 уровень сложности (человка, ветра, звука, света, бога)
```

призрак  
```
призрак - это запись как вы проходили уровень
призраки доступны в TimeAttack и ForDev
на уровень доступно 3 призрака
записи шифрованы
погрешность записи
разность позиций: x и y: 
    речь про одну переменную, 
    если он меньше 127, запись виде 1 байта, 
    если меньше 32512, то запись виде 2 байта, иначе 4 байта
угол: из 1 дробного числа в 1 байт, из 0..180 в 0..127 и +128 если знак -
код анимации и сторона движения: в 1 байт
скорость анимации: из 1 дробного числа в 1 байт, 
    128 если знак -, целое часть * на 8, дробное из 0..0.9 в 0..7
```
