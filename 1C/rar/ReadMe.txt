Важная информация
-----------------------------------------------------------------------

Текущая версия конфигурации "1С:Розница", редакция 2.2 предназначена
для использования с версией системы 1С:Предприятие 8 не ниже 8.3.8.2197


Описание изменений конфигурации.
Новая функциональность конфигурации описана в разделе "Администрирование"-"Описание изменений системы".

Предусмотрен переход на 1С:Розница (базовая) редакция 2.2 с 1C:Розница, редакция 1.0. 

Файл обновления 1cv8.cf доступен в разделе Дополнительные материалы каталога обновлений 
конфигурации https://releases.1c.ru/project/RetailBase10_82. 
Переход на редакцию 2.2 доступен, 
начиная с версии 1.0.19.16, при использовании версии младше 1.0.19 необходимо 
обновить программу. 
Инструкция по переходу находится в папке AddDoc дистрибутива конфигурации.
