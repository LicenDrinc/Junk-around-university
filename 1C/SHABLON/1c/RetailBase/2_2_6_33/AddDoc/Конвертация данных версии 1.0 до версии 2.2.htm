1С:Розница (базовая). Конвертация данных версии 1.0 до версии 2.2

Конвертация данных состоит из следующих этапов:

  1. Регламентная подготовка данных в версии 1.0 к обновлению конфигурации
  2. Обновление штатными средствами через файл cf с последнего релиза версии 1.0 до переходной конфигурации
  3. Непосредственно конвертация данных в переходной конфигурации
  4. Обновление штатными средствами через файл cfu с переходной конвертации данных до финальной версии
     

Сценарий конвертации

Действия в 1С:Розница версии 1.0

  • Файл обновления предназначен для перехода с версии 1.0.19. Если используется более младшая версия, то необходимо обновить конфигурацию.
  • Кассиры (старшие кассиры) закрывают смены. Если в результате учета денежные средства остались в кассах ККМ их следует перенести в операционные кассы.
  • Менеджеры внутренней логистики завершают операции перемещения по ордерной схеме
  • Администратор делает резервное копирование базы данных и проверяет бекап.
  • Если используется конфигурация версии 1.0.14.3 на платформе 8.1 необходимо сконвертировать конфиграцию под платформу 8.2
  • Администратор обновляет базу до переходной конфигурации. Файл обновления 1cv8.cf находится на сайте https://releases.1c.ru/project/RetailBase10_82 в каталоге установленного релиза 1С:Розница 1.0. При использовании версии младше 1.0.19 необходимо обновить программу. В конфигураторе "Конфигурация – Поддержка – Обновить конфигурацию – Выбор файла обновления" и далее обновить конфигурацию базы данных
  • Для пользователя, под которым будет проведена конвертация (далее "Пользователь конвертации") данных необходимо добавить доступные роли: "Администрирование", "Запуск толстого клиента", "Запуск тонкого клиента", "Полные права". Рекомендуется сразу установить Режим запуска "Управляемое приложение"

Действия в конфигурации 1С:Розница 2.2 (конвертация с версии 1.0)

  • Администратор запускает систему под Пользователем конвертации.
  • Автоматически открывается обработка "Конвертации данных"
  • Администратор принимает решение о переносе тех данных, которые переносить не обязательно. При отказе от переноса какой-либо информации администратор убирает соответствующий флаг
  • Администратор запускает процесс конвертации
  • Администратор обновляет базу до финальной версии конфигурации. Файл обновления 1cv8.cfu находиться в подкаталоге tmplts\1c\RetailBase\2_2_<Номер версии>_<Номер сборки>\ каталога установки 1С:Предприятия 8. В конфигураторе "Конфигурация – Поддержка – Обновить конфигурацию – Выбор файла обновления" и далее обновить конфигурацию базы данных.
  • Для Пользователя конвертации добавляется доступная роль: "Администратор системы"

Действия в конфигурации 1С:Розница 2.2

  • Проверить и настроить Параметры учета (Администрирование - Настройка параметров учета).
  • Проверить и дозаполнить реквизиты элементов справочника "Организации".
  • Проверить и дозаполнить реквизиты элементов справочника "Магазины". 
  • Сотрудник предприятия, ответственный за соответствующий блок неконвертируемой информации, вносит ее в систему.
  • Переносятся только наименования элементов справочника Скидки (наценки). Пользователю нужно создать условия скидок и настроить перенесенные скидки.
  • Проверить цены номенклатуры, т.к. записи по регистрам сведений "Цены номенклатуры" и "Цены номенклатуры в магазинах" из документов "Корректировка записей регистров" не переносятся.
  • Создать рабочие места, подключить оборудование, настроить Кассы и Кассы ККМ.
  • Настроить Шаблоны чеков ККМ и Шаблоны ПКО и РКО.
  • Установить границы дат запрета редактирования.
  • Настроить обмены данных, используемые на предприятии. История обменов не переносится.
  • Проанализировать внешние обработки в связи с изменением структуры метаданных.
  • Настроить регламентные задания.
  • После конвертации рекомендуется провести регламентную процедуру "Удаление помеченных объектов".

Другие ограничения переноса данных

  • В Рознице 2.2 не поддерживаются свойства документов и справочника Организации, и соответственно не конвертируются из Розницы 1.0
  • Свойства с типом значения «Классификатор единицы измерения» не переносятся
  • В Рознице 2.2 не поддерживается ставка НДС 20%.

Важно!

Сконвертированные из информационной базы конфигурации Розница 1.0 документы не рекомендуется перепроводить. Для поддержки этого ограничения рекомендуется установить дату последнего сконвертированного документа в качестве даты запрета редактирования. Если возникла необходимость скорректировать остатки товаров или денежных средств рекомендуется создать новые документы корректировок.
