Выгрузка данных из Торговля и склад 7.7

Ограничения выгрузки данных

  • Отрицательные данные по остаткам товаров не переносятся
  • Отрицательные данные по себестоимости товаров не переносятся
  • Отрицательные данные по остаткам денежных средств в операционных кассах не переносятся
  • Данные по остаткам денежных средств в денежных ящиках контрольно-кассовых машин не переносятся
  • Цены, рассчитываемые динамически, не переносятся. 
  • Не формируются документы ввода начальных остатков, в которых нет товарных строк
  • При переносе данных из Торговля и склад 7.7 множественные виды свойств объектов и свойства таких видов не переносятся  

Предварительные действия

  1. Выполните резервное копирование информационной базы конфигурации Торговля и склад 7.7 (Аспект 7.7). Если версия конфигурации Торговля и склад 7.7  ниже 7.70.974 , то проведите обновление конфигурации до указанной или более поздней версии.
  2. Закройте кассовые смены и инкассируйте денежные средства из контрольно-кассовых машин.
  3. Проверьте актуальность курсов валют.
  4. Для верификации данных по остаткам целесообразно провести инвентаризацию товарных остатков и остатков денежных средств. Устраните отрицательные данные по остаткам товаров, остаткам денежных средств в исходных базах. 
  5. Выполните все регламентные процедуры в конфигурации Торговля и склад 7.7: удалите помеченные объекты, установите дату актуальности итогов, при необходимости восстановите границу последовательности документов.

Выгрузка данных в файл обмена

  1. Внешняя обработка для выгрузки данных и файл правил обмена находятся в каталоге поставки конфигурации Розница 8 в подкаталоге Conv77_8.
  2. Откройте внешнюю обработку Tr77_Rt20.ert с помощью пункта меню Файл - Открыть. В появившемся диалоге укажите путь к файлу правил обмена Tr77_Rt20.xml и имя внешнего файла обмена, в который будет производиться выгрузка данных. После этого нажмите на кнопку Загрузить правила обмена.
  3. В диалоговом окне появится список объектов, которые могут быть выгружены (это может занять некоторое время). По умолчанию будет выгружена информация по константам, справочникам и остаткам, рекомендуемым к выгрузке. При необходимости можно отключить выгрузку информации по любому из справочников или отключить выгрузку остатков. Для задания даты выгрузки остатков используется параметр Дата выгрузки. В случае необходимости можно настроить параметры и задать условия отбора данных.



Параметры выгрузки данных устанавливаются на закладке Параметры:

  • Выгрузка в базовую версию
    Параметр применяется при выгрузке в базовую версию Розница 8 (версия 2.0).
    Если флаг установлен, то при выгрузке данных будет произведена фильтрация выгружаемых справочников и учетных данных по организации, заданной в параметре Организация (для базовой версии).
  • Организация (для базовой версии)
    Параметр применяется только при установленном параметре Выгрузка в базовую версию. В базовую версию Розница 8 будут выгружены данные по указанной организации.
  • Количество строк в документах.
    Допустимые значения - [0,99999]. Значение по умолчанию - 1000.
    Формируемые по учетным данным документы разбиваются по количеству строк в ТЧ, указанном в параметре.
    Количество строк в документе не может быть более 100000(ограничение 1С: Предприятие 8).
  • Разделитель телефонов
    Значение по умолчанию ",".
    Так как в Торговля и склад 7.7 в поле Телефон может быть указано несколько телефонов через символ-разделитель, для переноса данных необходимо указать значение символа-разделителя.
  • Магазин по умолчанию 
    Если параметр задан, то в конфигурации Розница 8 (версия 2.0) будет создан магазин, которым заполняться соответствующие реквизиты справочников "Склады", "Кассы", "Кассы ККМ", а так же документы "Оприходование товаров" и "Ввод остатков расчетов с поставщиками"

После настройки правил выгрузки данных необходимо нажать на кнопку Выгрузить. Данные будут выгружены в файл обмена.

Загрузка данных

Последовательно выполните действия, описанные ниже.

Предварительные действия

  1. Произведите установку конфигурации Розница 8 (версия 2.0). Создайте новую информационную базу конфигурации Розница 8 (версия 2.0).
  2. Настройте параметры учета подсистема "Настройка и администрирование", а также введите первоначальную информацию, которую не планируется переносить из информационной базы конфигурации Торговля и склад 7.7.

Загрузка данных из файла обмена в Розница 8 (версия 2.0)

Для загрузки данных выберите пункт меню Все функции - Обработки - Универсальный обмен данными в формате XML. В открывшемся диалоге на закладке Загрузка данных укажите режим работы на сервере, файл обмена, в который была произведена выгрузка, и нажмите на кнопку Загрузить данные. Данные будут загружены в информационную базу из файла обмена.

Заполнение прав пользователей

  • Необходимо настроить дополнительные права пользователей (Настройка и администрирование - Настройки пользователей и прав).

Заполнение справочников

  • В справочнике Магазины (Справочники - Магазины) создать и заполнить информацию о магазинах предприятия. При создании магазинов можно выбирать склады из ранее переданных из конфигурации Торговля и склад 7.7.

  • В справочнике Склады (Нормативно-справочная информация - Склады), в справочнике Кассы (Нормативно-справочная информация - Кассы), в справочнике Кассы ККМ (Нормативно-справочная информация - Кассы ККМ) в каждом элементе справочника заполнить информацию о магазине и организации.
  • Необхимо задать Наборы дополнительных реквизитов и сведений (Настройка и администрирование - общие настройки - Наборы дополнительных реквизитов и сведений).

Проведение документов

  • В регламентной обработке проведения документов (Все функции - Проведение докеументов)  выбрать из доступных документов: "Установка себестоимости", "Установка цен номенклатуры", "Ввод остатков денежных средств" и "Ввод остатков расчетов с поставщиками", задать период равный дате выгрузки, установить режим проведения: "Проводить непроведенные документы" и нажать кнопку "Провести".

Заполнение документов ввода начальных остатков

  • В документе Оприходование товаров (Склад - Оприходование товаров) в каждом документе заполнить магазин и организацию, а так же учетные цены номенклатуры (можно воспользоваться сервисом заполнения цен). Провести документ.

Проверка корректности перенесенных учетных данных

При переходе с Торговля и склад 7.7:

  • Для сверки данных по остаткам товаров на складах в Торговля и склад 7.7 используйте отчеты Ведомость по остаткам ТМЦ и Остатки ТМЦ, в Розница 8 (версия 2.0) отчет Ведомость по товарам на складах (Склад - Отчеты по складу - Остатки на складах).
  • Для сверки данных по остаткам денежных средств операционных кассах в Торговля и склад 7.7 используйте отчет Ведомость по кассе и рублевые показатели остатков в кассе, в Розница 8 (версия 2.0) используйте Остатки и движения денежных средств (Финансы - Отчеты по финансам - Наличные денежные средства).
  • Для сверки данных по себестоимости номенклатуры в Торговля и склад 7.7 используйте отчет Ведомость по партиям ТМЦ (установить "Бух. учет с НДС", дата окончания отчета = Дате выгрузки, без разделения по юр.лицам, детализация только по номеклатуре в основных единицах измрения), в Розница 8 (версия 2.0)используйте отчет Стоимостная оценка склада (Склад - Отчеты по складу - Оценка склада (в розничных цена)). Себестоимость выгружается только с НДС.
  • Для сверки данных по ценам номенклатуры в Торговля и склад 7.7 используйте обработку Печать прайс-листа (переключатель "Позиции прайс-листа" установить в позицию "Все"), в Розница 8 (версия 2.0) используйте Цены (по видам цен) (Маркетинг - Отчеты по маркетингу - Цены (по видам цен)).
  • Для сверки данных по расчетам поставщиков в Торговля и склад 7.7 используйте отчет Ведомость по контрагентам (вид отчета установить в позицию "По поставщикам",  установить "В валюте бух. учета"), в Розница 8 (версия 2.0) используйте отчет Состояние расчетов с поставщиками (Запасы и закупки - Отчеты по запасам и закупки - Состояние расчетов с поставщиками)

Если перенесенные данные не верны, то рекомендуется внести изменения в исходные базы, удалить в Рознице сформированные документы внесения первоначальных остатков и повторно выгрузить и загрузить данные, установив по необходимости новую дату выгрузки.
