1С:Предприятие 8
Конфигурация "1С:Розница", редакция 2.2
=================================================================
В этом файле содержится:

- Инструкция по подключению обновленных правил обмена между конфигурациями
"1С:Бухгалтерия предприятия 8", редакция 2.0 и "1С:Розница", редакция 2.2.

Инструкция
-----------------------------------------------------------------

Правила конвертации.XML - Правила обмена данными между конфигурациями "1С:Бухгалтерия
предприятия 8" и "1С:Розница".

Правила регистрации.XML - Правила регистрации объектов для обмена данными между
конфигурациями "1С:Бухгалтерия предприятия 8" и "1С:Розница".

Если обмен настраивается впервые:

Если первоначальная настройка информационной базы осуществляется в конфигурации
"1С:Розница", то после завершения работы помощника
настройки обмена данными на стороне конфигурации "1С:Бухгалтерия предприятия 8",
перед использованием помощника интерактивного обмена данными следует выполнить
действия, описанные в пункте "Если настройка обмена уже производилась ранее".

Если первоначальная настройка информационной базы осуществляется в конфигурации
"1С:Бухгалтерия предприятия 8", то при настройке обмена на стороне конфигурации
"1С:Бухгалтерия предприятия 8", в помощнике настройки обмена данными, на
последнем шаге снять флажок "Выполнить выгрузку данных сейчас". Далее перейти к
пункту "Если настройка обмена уже производилась ранее".

Если настройка обмена уже производилась ранее: 

В конфигурации "1С:Бухгалтерия предприятия 8" необходимо открыть форму списка
настроек обмена данными "Сервис" -> "Обмен данными с продуктами на платформе
1С:Предприятие 8.2" - > "Обмены данными".
Для каждого элемента списка, соответствующего настроенному обмену данными между
конфигурациями "1С:Бухгалтерия предприятия 8" и "1С:Розница" необходимо выполнить следующие действия:

- В форме настройки обмена, выбрать пункт меню "Параметры обмена данными" ->
"Открыть правила конвертации объектов".

- В открывшейся форме "Правила конвертации объектов" установить переключатель
в значение "Правила из внешнего файла" и воспользовавшись кнопкой "Загрузить правила", указать файл правил "Правила конвертации.XML". Закрыть форму
"Правила конвертации объектов".

- В форме настройки обмена, выбрать пункт меню "Параметры обмена данными" ->
"Открыть правила регистрации объектов".

- В открывшейся форме "Правила регистрации объектов" установить переключатель в
значение "Правила из внешнего файла" и воспользовавшись кнопкой "Загрузить правила", указать файл правил "Правила регистрации.XML". Закрыть форму
"Правила регистрации объектов".

Далее обмен данными можно осуществлять в обычном режиме.
